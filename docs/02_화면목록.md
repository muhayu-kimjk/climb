화면 ID는 `SCR-번호` 형식입니다. 앞자리는 화면 묶음을 뜻합니다: 0 로그인과 개요, 1 계약 등록, 2 계약 검토, 3 계약 체결과 운영 검토, 4 보관함, 5 관리자, 9 이용 안내, 공지사항, 내 계정. 업무 흐름 5단계(REQ-FLOW-13)의 단계 번호와는 같지 않습니다. 프로토타입 HTML 파일 맨 위 주석에 같은 ID를 적습니다.

"시안" 열의 **완료**는 프로토타입 화면이 만들어진 것, **예정**은 아직 만들지 않은 것입니다.

## 1. 메뉴 구조

메인 메뉴는 **개요 → 견적 → 계약 등록 → 계약 현황 → 보관함**(→ 관리자) **→ 공지사항** 순서입니다(REQ-UI-14, v0.37 공지사항, v0.54 견적). 업무 흐름 5단계(계약 등록 → 계약 검토 → 계약 체결 → 운영 검토 → 계약 완료, REQ-FLOW-13)는 메뉴와 따로 갑니다. 계약 검토, 계약 체결, 운영 검토는 "계약 현황"에서, 계약 완료는 "보관함"에서 봅니다. KRDS 메인 메뉴(상단 가로 메뉴) 구조를 따르며, 하위 화면이 있는 메뉴는 누르면 아래로 하위 메뉴가 펼쳐집니다. 메뉴 줄 오른쪽 끝에는 "이용 안내"를 둡니다.

메뉴는 역할에 따라 다르게 보입니다. (REQ-AUTH-11 [가정]) 최고관리자에게는 아래 메뉴가 모두 보입니다(REQ-AUTH-14). 역할은 분야와 등급(담당자, 리더, 임원) 2단계이고, 영업지원, 정보보호, 고객지원, 재무의 리더와 재무 임원은 그 분야 담당자의 메뉴를 함께 봅니다(v0.22, REQ-AUTH-01, 18). 관찰자는 모두에게 보이는 메뉴만 봅니다.

```

├─ 개요                         ← 로그인 후 첫 화면 (모두)
```
